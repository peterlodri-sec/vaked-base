
```bash
cd ide/vaked-ide

```

## ⚡ Automation Scripts & Pipeline Modules

- **`cloudbuild.yaml`**: GCP Cloud Build pipeline for Google Cloud ADK (Agent Development Kit) multi-agent systems on Gemini Enterprise Agent Platform.
- **`scripts/adk_multi_agent_system.py`**: Collaborative Multi-Agent System (Supervisor, Media Publisher, Steganography, RAG Search agents).
- **`scripts/soundcloud_publisher.py`**: SoundCloud Artist API v2 publisher with 1240x400 crystal waveform rendering & Telegram ASCII release cards.
- **`scripts/soundcloud_vinyl_publisher.py`**: 100% REST API-driven SoundCloud Vinyl On-Demand 24-bit uncompressed WAV master distribution engine.
- **`scripts/youtube_publisher.py`**: Automated YouTube Data API v3 publisher with Apple Silicon Videotoolbox GPU MP4 video encoding.
- **`scripts/album_orchestrator.py`**: Full E2E 8-track continuous album release & chapter marker generator.
